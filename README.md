# Salon Diva — Be the Spotlight

Static website for Salon Diva (hair, nails, lashes and body treatments), built from the Claude Design mockups.

- `index.html` — desktop layout and mobile layout (the mobile layout shows below 768px)
- `styles.css` — global styles, hover states and the desktop/mobile switch
- `script.js` — scroll reveal, gallery filters, booking form, mobile menu, lightbox and review dots
- `assets/` — optimised photos and logo

No build step. Open `index.html` locally, or view it live on GitHub Pages: https://0824622148.github.io/SalonDiva/

Placeholders to replace before launch: street address, client review names, Instagram and WhatsApp links. The booking form shows a confirmation message only; it does not send a request yet.
